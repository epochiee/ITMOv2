# ДЗ 5. Промпты двух команд

Каждая команда — отдельный агент без истории основного чата и без доступа к спеке другой команды до согласования. Оба получают один бриф (`00-brief.md`) и работают по skill `speckit-specify` (Spec Kit 1.2.4.dev0).

## Команда 1 — спека UI

```text
/speckit-specify
Ты — команда 1 (UI). Фича — в practices/practice_05/homework/00-brief.md.
Опиши экран и действия пользователя, состояния (пусто, загрузка, успех, пустой результат, ошибка)
и ошибки глазами пользователя. Каталог фичи: specs/001-changelog-preview-ui.
Формат API и правила валидации не решай. В конце спеки — раздел
«Ожидания от логики»: какие данные, вызовы и ошибки нужны экрану.
specs/002-* не читай. Код не пиши.
```

## Команда 2 — спека логики

```text
/speckit-specify
Ты — команда 2 (логика). Фича — в practices/practice_05/homework/00-brief.md.
Опиши данные, алгоритм, правила, операции API и виды ошибок.
Каталог фичи: specs/002-changelog-preview-api.
Вёрстку и тексты интерфейса не решай. Конкретику HTTP (пути, коды, JSON)
вынеси в раздел «Предлагаемый контракт» — его утвердят на согласовании.
В конце спеки — раздел «Ожидания от UI»: как клиент должен вызывать API
и что показывать на каждую ошибку.
specs/001-* не читай. Код не пиши.
```
