# ДЗ 5. Бриф фичи для двух команд

Одинаковый вход для обоих чатов. Команды не видят работу друг друга до этапа согласования контракта.

## Фича

**Локальный сервис предпросмотра changelog.** Разработчик запускает `changelog-gen-web`, открывает страницу в браузере, указывает диапазон коммитов и типы, сразу видит готовую секцию changelog и копирует её в `CHANGELOG.md` или в описание релиза. Сейчас для этого нужно запускать CLI с флагами и перенаправлять вывод.

## Что уже есть в проекте

- `changelog-gen [RANGE] [--types feat,fix]` — CLI (OpenSpec-спека `openspec/specs/changelog-cli/spec.md`; до archive — `openspec/changes/filter-commit-types/specs/changelog-cli/spec.md`): диапазон по умолчанию `HEAD`, фильтр типов, breaking-коммиты не отфильтровываются, неизвестный тип — ошибка, нераспознанные коммиты пропускаются с сообщением `skip:`.
- Ядро: `parser.parse_commit`, `parser.TYPES`, `renderer.render`.
- Конституция Spec Kit: `.specify/memory/constitution.md` (stdlib only, один разборщик, тест на каждое поведение, сервис только на 127.0.0.1, ввод не попадает в git как опция).

## Команды

| | Команда 1 — UI | Команда 2 — логика |
|---|---|---|
| Отвечает за | экран, действия, состояния, ошибки глазами пользователя | данные, алгоритм, правила, HTTP API, ошибки |
| Spec Kit | `/speckit-specify` → `specs/001-changelog-preview-ui/spec.md` | `/speckit-specify` → `specs/002-changelog-preview-api/spec.md` |
| Не решает | формат API и правила валидации | вёрстку и тексты интерфейса |

## Ограничения для обеих команд

- Один пользователь, локальная машина, без авторизации.
- Без новых зависимостей: стандартная библиотека Python, страница — HTML и JS без сборки.
- Поведение фильтра совпадает с CLI.

## Порядок

1. Каждая команда пишет свою спеку и список предположений о другой стороне.
2. Согласование: сверяем данные, вызовы, ошибки и состояния; решения принимает человек; результат — `specs/contracts/changelog-preview-api.md`, обе спеки обновляются.
3. После согласования: plan → tasks → реализация → сквозной сценарий и проверка ошибки/границы.
