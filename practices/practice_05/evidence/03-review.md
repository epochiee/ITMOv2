Отдельный агент (Claude Code subagent, без истории основного чата), промпт по слайду 9:


## Собственная находка автора (не от ревьюера)

На текущей версии `changelog-gen --output=pwned.txt` в чистом репозитории завершается кодом 0 и **создаёт файл** `pwned.txt`: аргумент целиком уходит в `git log` как опция. После перехода на `argparse` такой вызов даёт код 2, но `changelog-gen -- --output=x` по-прежнему передаст опцию в git. Для локального CLI риск низкий (пользователь и так управляет своей машиной), поэтому в это изменение не берём; записано в Risks. Для веб-сервиса из ДЗ это уже уязвимость — там ввод придёт по HTTP. Защиту (`--end-of-options` и проверку диапазона) переносим в спеку логики ДЗ.
