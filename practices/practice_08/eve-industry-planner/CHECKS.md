# Отчёт о проверках

Проверено 22 ноября 2026 года в Windows с Node.js 25.2.0 и npm 11.6.2.

| Что запускалось | Результат |
|---|---|
| `npm ci` | Зависимости установлены по lock-файлу, npm сообщил о 0 известных уязвимостях. |
| `npm run build` | Проверка TypeScript и сборка Vite прошли. Сборщик выдал предупреждения о директивах «use client» в Material UI. |
| `npm test` | Прошли 32 теста: 7 для доменной функции, 22 для HTTP API, 3 сценария формы. |
| `npm run test:integration` | Microsoft Edge прошёл контрольный заказ через собранный клиент и запущенный Express API. |
| `npm run test:integration` с `TEST_DEV=1` | Тот же браузерный сценарий прошёл через сервер разработки `npm run dev`. |

Браузер отправил заказ на 10 щитовых модулей. Полный ответ API совпал с контрольным примером. На экране проверены материалы на 320 000 ISK, производственная себестоимость 340 000 ISK, полные затраты 350 000 ISK, выручка 450 000 ISK, прибыль 100 000 ISK и цена безубыточности 35 000 ISK за изделие. На экране шириной 360 пикселей проверено отсутствие горизонтального переполнения страницы. При изменении числа запусков появилась отметка об устаревшем результате.

В доменных тестах проверены прибыль, убыток, выход в ноль, округление половин вверх, выпуск 100 боеприпасов за запуск и суммы выше безопасного целого JavaScript. Для партии стоимостью 101 ISK из 100 боеприпасов получены 1,01 ISK за единицу и 2 ISK для безубыточной продажи.

Тесты формы воспроизвели загрузку, ошибку и пустой ответ каталога, ошибки полей без сетевого запроса, смену рецепта, сбой расчёта с сохранением ввода, повторную попытку и блокировку дублирующей отправки.
