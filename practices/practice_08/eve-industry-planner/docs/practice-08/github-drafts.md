## Issue

**Заголовок** — Проверить передачу фокуса и защиту от повторной отправки заказа

**Шаги проверки**

1. Запустить калькулятор. Нажать `Tab`, выбрать чертёж клавишей со стрелкой и заполнить контрольный заказ из [README защиты](README.md).
2. Оставить цену продажи пустой и запустить расчёт. Ожидается подсказка «Введите сумму в ISK», фокус на поле цены и отсутствие `POST`.
3. Запустить `npm run test:integration -- integration/states.spec.ts`. Ожидается, что при задержанном ответе двойной клик и повторный `Enter` оставят один запрос, а после HTTP 500 введённые суммы сохранятся.
4. Запустить `npm run test:integration -- integration/order.spec.ts`. Ожидается HTTP 200 от Express, прибыль 100 000 ISK и фокус на заголовке результата.

Браузерные команды требуют готовой сборки. Её можно получить через `make build`.
