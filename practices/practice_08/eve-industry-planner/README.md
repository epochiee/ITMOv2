# Верфь

Одноэкранный калькулятор производственного заказа для игроков EVE Online. Выберите чертёж, укажите число запусков и введите цены в ISK. Форма сразу покажет количество материалов и выпуск. Кнопка «Рассчитать» отправляет заказ локальному серверу и выводит себестоимость, выручку, прибыль или убыток и цену безубыточности.

## Практика 8

Интерфейс использует **Material UI 7**. Тема в [client/main.tsx](client/main.tsx) задаёт палитру, шрифты, скругление и шаг отступов. В форме и сводке используются `TextField`, `Button`, `Paper`, `Alert` и `CircularProgress`.

[README для защиты](docs/practice-08/README.md) содержит сценарий расчёта, соответствие критериям, команды проверки и разбор вклада AI. [Интерактивный HTML-прототип](docs/practice-08/prototype.html) открывается локально в браузере.

## Локальный запуск

Понадобятся Node.js 22.13 или новее и npm. Выполните в каталоге проекта:

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. Клиент и Express API работают на одном адресе. Для запуска готовой сборки выполните:

```sh
npm run build
npm start
```

Готовая сборка доступна на http://127.0.0.1:3000. Порт обоих режимов можно изменить переменной окружения `PORT`.

## Данные и расчёты

Каталог в `catalog/blueprints.json` содержит три условных рецепта. Цены задаются вручную за единицу материала и изделия. Оба сбора фиксированы для всей партии. Пустое поле цены требует ввода, ноль допустим. При смене чертежа сохраняются число запусков, сборы и цены общих материалов. После изменения заказа предыдущая сводка получает отметку об устаревании.

Модель охватывает одну одноступенчатую партию. Рыночные данные, игровые бонусы, налоги и история заказов в MVP не входят. Расчёты выполняются на сервере в целых ISK через BigInt. Удельная себестоимость округляется до сотых по правилу половины вверх, а цена безубыточности — вверх до целого ISK.

## HTTP API

`GET /api/v1/blueprints` возвращает объект с массивом `blueprints`. Каждый чертёж содержит ID, название, изделие, выпуск и нормы материалов.

`POST /api/v1/calculations` принимает JSON с заголовком `Content-Type: application/json`. Все поля обязательны. Число запусков — целое JSON-число от 1 до 10 000. Каждая сумма — строка из десятичных цифр от 0 до 1 000 000 000 000 в канонической записи. Карта цен содержит ровно материалы рецепта.

```json
{
  "blueprintId": "shield-module",
  "runs": 10,
  "materialUnitPricesIsk": { "tritanium": "1000", "pyerite": "1200" },
  "jobFeeIsk": "20000",
  "saleFeeIsk": "10000",
  "saleUnitPriceIsk": "45000"
}
```

В ответе `200` поля `productQuantity` и `materials[].quantity` содержат объёмы партии, а `totals` — денежные строки и исход. Для примера выше выпуск составляет 10 модулей. На них потребуется 200 единиц тританиума и 100 единиц пайерита.

| Показатель | ISK |
|---|---:|
| Материалы | 320 000 |
| Производственная себестоимость | 340 000 |
| Полные затраты | 350 000 |
| Удельная себестоимость | 35 000,00 |
| Выручка | 450 000 |
| Прибыль | 100 000 |
| Цена безубыточности за модуль | 35 000 |

Ошибки возвращаются в объекте `error` с полями `code` и `message`. Сервер отвечает `400 INVALID_JSON` при ошибке синтаксиса, `422 VALIDATION_ERROR` с картой сообщений `fields` при ошибках параметров и `500 INTERNAL_ERROR` при внутренней ошибке.

## Проверки

```sh
npm run test:client
npm test
npm run build
npm run test:integration
```

Vitest проверяет расчёты, HTTP API и поведение формы. Команда `npm run test:client` запускает только тесты формы. Playwright поднимает собранное приложение на порту 4187, проходит контрольный заказ через Express и проверяет состояния интерфейса с подменой ответов. В Windows используется установленный Microsoft Edge. Для Chrome задайте `BROWSER_CHANNEL=chrome`. В Linux и macOS перед первым браузерным тестом выполните `npx playwright install chromium`.

Команда `make verify` выполнит Vitest, сборку и браузерные тесты. Результаты практики приведены в [выводе команд](docs/practice-08/test-results.txt). [Отчёт о проверках MVP](CHECKS.md) описывает исходную версию.
