Сырые ответы MCP tool parse_commit (сервер changelog-gen), живая сессия в песочнице changelog-gen-exp.
Тайм-коды не включены.

=== Фаза B: три темы из промпта ===

> parse_commit(message="feat(api)!: drop v1")
{
  "ok": true,
  "type": "feat",
  "scope": "api",
  "description": "drop v1",
  "breaking": true
}

> parse_commit(message="fix: handle empty log")
{
  "ok": true,
  "type": "fix",
  "scope": null,
  "description": "handle empty log",
  "breaking": false
}

> parse_commit(message="update stuff")
{
  "ok": false,
  "error": "not a Conventional Commit header: 'update stuff'"
}

=== Фаза D: темы коммитов диапазона v0.2.0..HEAD (шаг 3 skill release-notes) ===

> parse_commit(message="wip stuff")
{
  "ok": false,
  "error": "not a Conventional Commit header: 'wip stuff'"
}
