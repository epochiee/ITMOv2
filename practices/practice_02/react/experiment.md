# ReAct

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

 - Цель: привести сценарий «Большой diff 60 KB» к проверяемому виду, согласованному с problem.md и adr.md.
 - Доступные входы: practices/practice_01/problem.md, practices/practice_01/adr.md, practices/practice_01/tests_load.md.
 - Разрешённые действия: чтение указанных файлов; одно редактирование tests_load.md.
 - Запрещённые действия: внешние источники, изменение структуры таблицы, правки других файлов.
 - Максимальное число шагов: 2.
 - Условие остановки и вопроса человеку: строка обновлена и согласована; если нужен внешний источник — остановиться и спросить.
