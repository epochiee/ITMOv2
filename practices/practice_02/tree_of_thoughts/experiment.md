## Запрос


Предложи три альтернативы постановке SLA для сценария «Большой diff» в tests_load.md с разными допусками и критериями. Сравни по критериям: соответствие problem.md, проверяемость, риск ложных срабатываний.
## Варианты решения

| Альтернатива | Плюсы | Минусы | Оценка по критериям |
|---|---|---|---|
| A: P95 <= 5s; >= 99% 2xx | Соответствует problem.md; просто проверять | Может скрывать хвосты распределения | Высокая согласованность, высокая проверяемость, низкий риск |
| B: P90 <= 4s; >= 99.5% 2xx | Строже, лучше UX | Риск ложных отказов; нет источника | Средняя согласованность, средняя проверяемость, высокий риск |
| C: P95 <= 6s; >= 98% 2xx | Гибкость под большие диффы | Неполное соответствие SLA | Низкая согласованность, высокая проверяемость, средний риск |

## Выбор

- Выбранная альтернатива: A (P95 <= 5s; >= 99% 2xx).
- Почему: полностью соответствует SLA в problem.md, легко проверяется стандартными инструментами нагрузки, минимизирует риск ложных срабатываний.
- Как проверим: прогоним сценарий «Большой diff 60 KB» и подтвердим, что P95 <= 5s и доля 2xx >= 99% в течение 10 минут.
